# 안심 드라이브 (부모님 안심 드라이브) 데모

현대 Pleos Playground 차량용 앱 공모전 출품용 프로토타입.

- `app/` : Android(Kotlin, Jetpack Compose) 차량 앱. Pleos Connect 에뮬레이터(AAOS)와 일반 안드로이드 에뮬레이터 모두에서 실행.
- `web-demo/index.html` : 같은 화면 흐름을 브라우저에서 보는 시연 페이지. 영상 녹화용 "자동 시연" 버튼 포함.

## 핵심 기능

| 기능 | 데모 | 실차 연동 계획 |
|---|---|---|
| 쉬운 길 (고속도로 0km 우선) | 고정 경로 데이터 | Pleos NaviHelper `RouteOption.COMFORTABLE` 탐색 후 고속도로 구간 길이로 정렬 (공식 "고속도로 회피" 옵션은 없음) |
| 자녀에게 목적지·도착 공유 | 오른쪽 "자녀 폰" 미리보기 | 서버 경유 FCM 푸시 / 문자 |
| 에어백 전개 → 즉시 자녀 알림 | "에어백" 시연 버튼 | Vehicle SDK Safety `registerSeatAirbagDeployed` (권한 CAR_SAFETY) |
| 급정지 후 무응답 → "괜찮으세요?" → 30초 후 알림 | "급정지" 시연 버튼 | AAOS Car API 차량 속도 (권한 CAR_SPEED) |
| 비상등 켜고 천천히 정차 → 알림 없음 | "비상등 정차" 시연 버튼 | 같은 규칙 (급감속이 아니면 무시) |

사고 의심 규칙은 `app/src/main/java/com/ansimdrive/demo/safety/SafetyMonitor.kt` 한 곳에 있고, 단위 테스트(`SafetyMonitorTest`) 6개가 통과한다.
40km/h 이상에서 초당 25km/h 이상(약 0.7G) 감속해 멈춘 뒤 5초간 움직임이 없으면 묻는다.

## Android Studio에서 실행하기

1. [Android Studio](https://developer.android.com/studio) 최신 버전 설치.
2. Pleos Connect 에뮬레이터 설치: Pleos Playground 개발자 문서(document.pleos.ai)의 에뮬레이터 안내대로 시스템 이미지(v2.1.0)를 추가한다. 안 되면 일단 **Device Manager → Automotive** 기본 이미지(가로 화면)로 해도 된다.
3. Android Studio에서 **File → Open** → 이 폴더(`ansim-drive`) 선택. Gradle 동기화가 끝날 때까지 기다린다 (처음엔 몇 분 걸림).
4. 상단 기기 목록에서 에뮬레이터를 고르고 ▶ **Run 'app'**.
5. 에뮬레이터 설정에서 언어가 한국어가 아니면 음성("괜찮으세요?")이 안 나올 수 있다. 설정 → 시스템 → 언어에서 한국어 추가, 또는 TTS 엔진에 한국어 음성 설치.

빌드 오류가 나면 오류 메시지 전체를 복사해서 보내 주면 고친다.

## 시연 영상 녹화하기

**에뮬레이터:** 에뮬레이터 옆 툴바 `⋯` (Extended controls) → **Record and Playback** → Start recording → 끝나면 Stop → WEBM/GIF로 저장.
**브라우저 데모:** `web-demo/index.html` 을 열고 "▶ 자동 시연"을 누른 뒤 화면 녹화.
- Mac: `Cmd + Shift + 5` → 선택 부분 녹화
- Windows: `Win + Alt + R` (Xbox Game Bar) 또는 Clipchamp 화면 녹화

자막·음성은 상단 버튼으로 끌 수 있다. 내레이션을 따로 녹음할 거면 음성을 끈다.

## 아직 확인할 것

- Pleos Connect 에뮬레이터 Virtual Console로 속도·에어백 값을 넣을 수 있는지. 가능하면 `MockVehicle` 대신 실제 신호를 읽는 구현으로 바꿔 시연 버튼 없이 보여줄 수 있다.
- 이 저장소의 앱 코드는 클라우드 환경에서 Android SDK를 받을 수 없어 APK 빌드까지는 확인하지 못했다. 사고 판단 로직 단위 테스트만 JVM에서 통과 확인.
